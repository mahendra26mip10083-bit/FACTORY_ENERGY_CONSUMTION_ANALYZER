# FOCTORY ENERGY COMSUMTION ANALYZER

## introdution
This is the Pythone project made to check the energy comsution of machine is used in Facrtory.The program takes machine details like power , running running hours and working days and calculates the energy comsumtion in KHh.

## feactures
1. add machine deatails
2. Display machine data
3. Calculate total energy comsumtion 
4. calculate elecricity coast
5. Give energy comsumtion suggestion

## Energy formula 

Energy = power * Runnning hours * working days

## Project file

   Contains the main menu and connect all other modules
